# 1MK — One-Man Kanban

Manifesto in progress: *One-Man Kanban: how to get the right things done and stay sane in the AI era.*

## Canonical files

Everything we collaborate on lives in this folder so it can be checked into the repo. No parallel copies in auto-memory, no outlier files in session scratch.

- `raw-notes.md` — outline-stage working draft. Re-read before acting; it changes faster than any snapshot.
- `memory/` — persistent project context. `MEMORY.md` is the index; individual files hold detail.
- `memory/project_1mk_manifesto.md` — vocabulary, conceptual framework, register.
- `memory/project_1mk_raw_notes_state.md` — last-known state of what's drafted vs. placeholder in raw-notes.md.

When you learn something durable about the project, write it to a new file under `memory/` and add a one-line pointer to `memory/MEMORY.md`. Do not write 1MK content to the global auto-memory location — that folder may hold a single pointer back here, nothing more.

## Working conventions

- Register: manifesto, not how-to guide. Robert is making an argument.
- Vocabulary is load-bearing: **Outcome** (replaces GTD *Project*), **Deliverable** (an artifact, AI- or human-produced), **State of Play** (replaces *Next Action*), **Mind Dump**, **Weekly Retrospective**. Full mapping and reasoning in `memory/project_1mk_manifesto.md`.
- AI/no-AI split is a core constraint: working memory and mind dumps are *not* shared with AI; everything else is.
