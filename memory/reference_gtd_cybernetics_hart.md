Source: Duncan Hart, "The Cybernetics of David Allen's Getting Things Done (GTD®)",
LinkedIn Pulse, 2026-09-06. Original: https://www.duncanhart.com/gtd-cybernetics

**Hart's argument:** GTD is applied cybernetics without ever citing it.
- Externalisation = Ashby variety attenuation. Environment generates unbounded variety;
  working memory holds ~nothing; the trusted system absorbs the gap.
- Completeness is emergent: a 90%-complete store gives ~0% benefit, because the brain
  cannot know which 10% leaked and so resumes monitoring everything.
- One inbox + one clarifying flowchart = a single transduction boundary converting
  undifferentiated "stuff" into a closed set of internal states. Failure mode: leaky boundary.
- Weekly Review = the feedback loop / error-correction mechanism. Skip it and you have an
  open-loop controller: the model drifts, trust collapses, monitoring returns.
- Horizons of Focus = recursion; each level sets reference values for the one below.
  Runway-first is a viability claim, isomorphic to VSM: S4/S5 cannot function while
  management is dragged into S1 firefighting.
- VSM mapping: next-action lists = S1; calendar + contexts = S2 (anti-oscillation);
  weekly review = S3/S3*; someday-maybe + upper horizons = S4; purpose/principles = S5.
- Gap 1: GTD has no outward-scanning S4 — nothing goes looking for what you weren't sent.
- Gap 2: the lists are flat; no model of feedback *between* commitments (assumes weak coupling).
- Gap 3 (his strongest): feedback runs upward as compliance, not challenge. Nothing checks
  whether the horizons should survive contact with what the runway reports.

**Why it matters to 1MK:**
- Ashby gives 1MK a sharper premise than "levels of tracking differ": GTD had only
  attenuation available. AI adds *amplification* of the regulator. Two levers, not one.
- Robert's outcome-loops-containing-agentic-loops IS Beerian recursion; agents become
  S1 units the human regulates. Justifies the Loops-within-Loops section theoretically.
- **Weekly Retrospective** (vs Review) is precisely the fix for Hart's gap 3 — retro asks
  whether the thing being pursued is still the right thing. The rename is load-bearing.
- **Monthly gap-spotting** is outward-scanning S4 — the thing GTD couldn't afford and
  agents make cheap. Closes Hart's gap 1.
- **Working memory file** = S2 anti-oscillation across parallel agents; agentic parallelism
  makes commitment coupling strong, so Hart's gap 2 stops being tolerable.
- **Context cleanup (review/amend/approve)** answers a problem Hart can't see: an
  AI-populated store can be complete and still untrusted, because trust in GTD was
  manufactured by the human processing each item. Approval is trust-manufacturing, not admin.

**Open challenge to 1MK:** Hart's completeness claim cuts against 1MK dropping
"One System to Rule Them All" (separate work/personal boards) and withholding working
memory + mind dumps from AI. 1MK needs an explicit answer — likely that completeness is
required *per boundary of accountability*, not globally. Not yet argued in raw-notes.md.

**Register caution:** 1MK is the lighter, heretical break from GTD. Use cybernetics as
engine room, not showroom — take the structural claims, leave the Ashby/Beer vocabulary out
of the front matter.

## Second pass — deeper implications (2026-09-07)

**Transducer.** Hart: GTD needs one boundary + one algorithm (the clarifying flowchart);
failure mode is the leaky channel. 1MK has many input channels, so on Hart's terms it looks
leaky. Resolution: the clarifying *algorithm* is now automatable — the Daily Briefing prompt
is the transducer. Boundary integrity moves from the channel to the ritual. Requires the
closed set of internal states to be machine-legible: 1MK's columns already are that state
machine. Corollary: an unreviewed AI deliverable is Hart's "captured but not clarified" —
noise inside the perimeter consuming attention. Gives Cognitive Debt a precise mechanism.

**Direction of viability = 1MK's missing upside argument.** Hart's runway-first claim
(S4/S5 impossible while dragged into S1 firefighting) implies the positive case 1MK does not
yet make: if agents stabilise operations, high-altitude thinking becomes available to people
who never had capacity for it. Notes are currently defensive (Four Horsemen) with no
offensive frame; "get the right things done" is under-argued relative to "stay sane".
Honest counter to include: supervising N parallel agents IS operational load. The conditional
is that orchestration beats execution only when state of play is externalised.

**Allocation claim (candidate thesis statement):** AI may occupy S1, assist S2/S3, inform S4
— never S5. S5 is where existential accountability lives, which is Robert's premise restated
in Beer's terms. The instrument that detects divergence must not be the one that arbitrates
it, or Cognitive Servitude. Candidate diagram: the 1MK/VSM allocation table.

**Annual reflection gets a new capability, not just a rename.** Hart's best line — a decade
of flawless execution against a purpose your own next-action lists were quietly refuting.
GTD's review could never trend that; nobody reads three years of their own lists. An AI
reading board history can. Mechanises Hart's governance gap rather than only naming it.
