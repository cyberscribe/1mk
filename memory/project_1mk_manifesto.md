Project: writing a manifesto titled **One-Man Kanban: how to get the right things done and stay sane in the AI era** (workspace: `/Users/rpeake/workspace/projects/1mk`).

**Why:** GTD principles are partly sacred and partly outdated in the AI era. The central new claim is a level-of-tracking split: humans track **outcomes** (existentially accountable to other humans for them); AI tracks **deliverables** (accountable to the human who asked). The manifesto articulates the system and its rationale.

**How to apply:**
- Vocabulary (as of 2026-05-13 — note the shift from earlier drafts):
  - **Outcome** replaces GTD's *Project*. Outcomes are human-accountable.
  - **Deliverable** is its own term: an artifact (doc, image, code change, API call, email) — AI produces some; humans and colleagues produce others.
  - **State of Play** replaces *Next Action*. Covers Current Status and/or Next Step.
  - **Mind Dump** replaces *Mind Sweep*.
  - **Weekly Retrospective** replaces *Weekly Review*.
  - **Project Support** unbundles into *Likely Sequence / Acceptance Criteria / Deliverable-specific data*.
  - Agile borrowings: daily team standup → self-standup with AI assistance; fortnightly retrospective → weekly self-retrospective with AI assistance.
- Frame arguments around the **Four Horsemen of the Personal AIpocalypse**: Cognitive Load, Cognitive Servitude (vs. Sovereignty), Cognitive Dependence, Cognitive Debt — with remedies grouped as: Human Recognises (outcomes / states of play / likely sequence / acceptance criteria); Human Externalizes (working memory + collaboration metadata); For AI Human Defines (protocols, deliverables, deliverable acceptance criteria); AI Cascades (working memory → deliverable-specific data → outcome-related data → durable reference data → collaboration protocols); Shared Rituals (daily briefing, weekly retro, monthly gap-spotting, annual reflection); Context Cleanup (review/amend/approve AI-generated artifacts).
- Respect the AI/no-AI split: **working memory and mind dumps are NOT shared with AI**; boards, columns, outcome/durable/collaboration files, email + messaging inputs, own externalisations, AI summaries and deliverables ARE shared.
- Loop ontology to preserve: **Open loops** (Zeigarnik/Allen) + **Agentic loops** (robotics input→reason→act→evaluate) + **Outcome loops** (human orchestration of many deliverable loops). The system's purpose is to let humans *pause without exiting* an outcome loop, freeing attention.
- Register: **manifesto**, not how-to guide. Robert is making an argument, not just documenting a system.
